# 노드 데이터 설명 (2026-11-18, B)

## 파일
- `food_nodes_1118_B.csv`: 18노드 (depot 2: D1 북항 부산항국제여객터미널, D2 영도 크루즈터미널 / 음식·관광 16: N01–N16). 업소 개인이 아닌 골목·시장 단위.
- `travel_time_1118_B.csv`: 모든 순서쌍(from≠to). mode=taxi는 전 쌍, mode=walk는 직선거리 1.5km 이하 쌍만 추가.

## 컬럼
node_id, name_ko, name_en, gu, category, lat, lon, open_min/close_min(자정 기준 분), meal_flag(1=식사), stomach(포만 단위 0.3–2), stay_min, price_krw(1인 통상), wait_peak_min, wait_source, busan_score(0–100 부산성: 기원·정체성·서사), narrative_tag(피란/항구/교류/근대/현대), hours_source, coord_source, note.

## 출처
- 좌표: OSM Nominatim(coord_source에 표기). 1차 미검출 8곳(N02,N03,N04,N05,N07,N11,N13,N16)은 도로명/지명으로 재지오코딩(2026-11-18) — 도로·지명 중심점이므로 실제 점포와 100–300m 오차 가능.
- 이동시간 taxi: OSRM 공개 데모 table API(car, 실시간 교통 미반영) → source=OSRM. 실패 시 모형 8+km×1.35/22×60.
- 이동시간 walk: 모형 km×1.3/4.5×60 (source=모형추정, 우회계수 1.3·보속 4.5km/h).

## 한계 (중요)
- 웹 출처 반영(2026-11-18 WebSearch, 여행/블로그 사이트, 공식 아님): 영업시간 N01,N05,N07,N08,N09,N16; 가격 N08; 대기 N16(사례 기반 분 추정). URL은 hours_source/wait_source.
- 나머지 영업시간·대기·가격과 포만도·체류시간·busan_score는 **추정치**. 업소·요일·휴무일별로 다름(자갈치 화요일 휴무 출처상이).
- busan_score와 narrative_tag는 팀 판단 기반 주관값.
- OSRM은 정체·신호를 반영하지 않아 피크시간 택시시간을 과소추정할 수 있음. 영도↔북항은 다리 경유.
- 자갈치시장 OSM 결과가 서구 충무동으로 나와 중구 기준 수동 좌표 사용.
