## 결론 먼저

1. **수업 코드는 우리 프로젝트와 같은 뼈대다.** 경주 예제 = "데이터랩 원천 CSV 병합 → 명절 보정 → DiD → 행정동별 전환비 → TSP/오리엔티어링 동선 → folium 지도 → 시나리오 비교표". 우리는 경주를 부산 크루즈로, 안동을 제주·인천/비기항일로 바꾸면 된다.
2. **그대로 쓸 함수 6개**: `load_raw_csv_series`, `build_daily_merged_dataset`(패턴), `evaluate_did_andong`, `build_dong_spatial_dataset`, `build_folium_route_map`, `run_gyeongju_policy_simulator`(표 형식). 원본은 `00_대회·수업자료/수업코드/경주_수업노트북_20261113.ipynb` 셀 번호로 아래에 적었다.
3. **B의 OPTW는 수업 코드보다 한 단계 위다.** 수업은 탐욕법(greedy) + 2-opt라 최적해 보장이 없고 시간창·대기가 없다. → 같은 노드로 수업식 탐욕 코스와 우리 OPTW를 둘 다 돌려 "만족도 +X, 대기 −Y분"을 비교하면 '모델 적합성' 점수 근거가 된다.
4. **SIR(바이럴 확산 모델)은 우리에게 안 맞는다.** 크루즈 승객 수는 입항 스케줄로 이미 정해져 있어 '확산'이 아니다. 수업에서 SIR이 하던 역할(추가 방문객 추정)은 **입항 승객 × 상륙률 × 루트 소비액**으로 대신한다.
5. **수업 데이터는 '내국인(KT 통신)' 기준이다.** 크루즈 승객은 외국인이므로, 데이터랩에서 **외국인 방문자·외국인 관광소비(카드)** 메뉴가 구 단위·일 단위로 있는지 A가 가장 먼저 확인해야 한다. [확인 필요]

### C. 인문 서사·텍스트 분석

- **스무딩 로그승산비(1주차)**: `ln[(f_a(w)+α)/(N_a+Vα)] − ln[(f_b(w)+α)/(N_b+Vα)]`. 수업 함수(`geoje_analytics.compute_log_odds_ratio`)는 공개되지 않아 아래처럼 직접 쓴다(검증 완료).

  ```python
  import numpy as np, pandas as pd

  def log_odds(counts_a, counts_b, alpha=1.0):
      """양수 = a 그룹에서 더 많이 언급, 음수 = b 그룹."""
      df = pd.DataFrame({"a": counts_a, "b": counts_b}).fillna(0)
      V = len(df)
      pa = (df["a"] + alpha) / (df["a"].sum() + V * alpha)
      pb = (df["b"] + alpha) / (df["b"].sum() + V * alpha)
      df["log_odds"] = np.log(pa / pb).round(3)
      return df.sort_values("log_odds", ascending=False)

  # 예: 서양권 vs 중국어권 리뷰의 메뉴 언급 수
  log_odds({"밀면": 40, "돼지국밥": 30, "씨앗호떡": 25, "어묵": 5},
           {"밀면": 10, "돼지국밥": 5, "씨앗호떡": 15, "어묵": 30})
  # → 돼지국밥 +1.16, 밀면 +0.83, 씨앗호떡 0.00, 어묵 −2.13
  ```

- **중요한 차이**: 수업은 한국어 댓글 하나를 '밈 전/후'로 나눴다. 우리는 **언어가 다른 리뷰끼리** 비교하므로 단어가 그대로 겹치지 않는다. → 형태소 분석 대신 **메뉴·노드 사전**(밀면 = milmyeon / wheat noodle / 小麦冷面 / ミルミョン …)을 만들어 언어별 언급 수를 세고, 그 수로 로그승산비를 낸다. 이러면 중국어·일본어용 분석기(Colab 미설치)도 필요 없다.
- 결과 → `국적가중치_MMDD_C.csv`: `w = exp(log_odds)`를 정규화해 쓰는 식이 가장 단순. 일본어 열(`w_jp`)이 필요한지 B와 맞출 것.
