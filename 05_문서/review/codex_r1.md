검토 범위: 요청한 README, 수업코드 분석, Python 3개, 정제 CSV·MD 전체, 출처목록·항만 비교, 서사카드. B 전체 실행은 하지 않았다. A 스크립트도 산출물을 덮어쓰므로 실행하지 않고 원자료 집계 부분만 메모리에서 재계산했다. 외부 기사 원문의 진위를 새로 검증한 보고서는 아니며, 출처 상태는 저장된 자료 기준이다. 프로젝트 수정은 이 보고서뿐이다.

## 1. [높음] 기다리면 가능한 식사를 탈락시켜 ‘정확해’ 보장이 성립하지 않음

- **위치:** `03_코드/cruise_route_optw.py:180`, `:195`, `:197` (정확해 표기 `:20`).
- **문제:** 영업 시작 전 대기만 허용한다. 식사 시간창, 이전 식사 후 120분, 소화 조건을 만족할 때까지 기다리는 선택은 탐색하지 않는다. 시간대에 따라 대기가 줄어드는 목적함수에서도 가장 이른 방문만 평가한다.
- **구체적 실패:** 메모리상 depot+식사 노드 1개, 10:50 출발·편도 1분·식사 30분·대기 0·승선마감 13:00으로 실행하면 `solve(k=1)`은 빈 목록이다. 실제로는 10:51 도착 후 11:00까지 9분 기다려 식사하고 11:31 복귀할 수 있다. 실데이터에서도 유효 경로와 더 좋은 방문 시각을 누락할 수 있다.
- **수정:** 식사창 시작·식사 간격 충족·소화 충족·혼잡 구간 경계 등 의미 있는 대기 시점을 탐색하고 그 시간에 비용을 부과한다. 구현 전에는 ‘즉시 방문 정책 내 최적’으로 한정한다.

## 2. [높음] 체류 중 소화가 누락되어 위 용량 제약이 과도하게 작동

- **위치:** `03_코드/cruise_route_optw.py:190`, `:201`.
- **문제:** `st`는 식사/섭취 시작 시점의 포만도인데, 다음 재귀의 기준시각은 체류 종료인 `end`다. 다음 노드에서는 `begin - t`만 소화시켜 이전 노드의 `stay_min` 동안 소화가 전혀 일어나지 않는다.
- **구체적 실패:** 2개 비식사 노드를 각각 포만도 2.5·체류 100분, 모든 이동 1분으로 만든 반례에서 반환 경로는 단일 방문 두 개뿐이다. 연속 소화 모델이라면 첫 섭취 후 101분이 지나 두 번째 섭취 직후 `2.5 - 1.01 + 2.5 = 3.99 ≤ 4`이므로 두 곳 모두 방문 가능하다.
- **수정:** 포만도와 시각의 기준을 일치시킨다. 종료시각 상태를 쓴다면 재귀에 `max(0, st - stay_min / DIGEST_MIN)`을 넘긴다. 섭취를 시작/종료 중 언제 반영하는지도 명시한다.

## 3. [높음] 탐욕 기준선과 OPTW의 제약이 달라 알고리즘 개선 효과를 비교할 수 없음

- **위치:** `03_코드/cruise_route_optw.py:226`, `:251`; `03_코드/run_B_model.py:119`.
- **문제:** 탐욕법은 대기·시간창뿐 아니라 최대 7곳, 위 용량, 식사 간격·시간창, `must_far`도 계획에 반영하지 않는다. 사후 `evaluate` 역시 영업종료·복귀만 확인하고 나머지 제약은 검증하지 않는다.
- **구체적 결과:** S1 기준선은 12곳·21:11 복귀·목적함수 736.2인 불가능 경로다. 이것을 7곳 제한 OPTW의 대기와 비교하면 방문 수 감소와 제약 추가 효과가 섞인다. ‘분기한정이라 성능 향상’의 근거가 되지 않는다.
- **수정:** 동일 제약·목적함수의 feasible greedy를 별도 기준선으로 만들고 동일 평가기로 검증한다. 현재 기준선은 ‘제약을 무시한 계획의 위험’ 사례로만 남긴다. 영업종료 위반까지 합쳐진 `on_time=False`를 전부 ‘승선마감 초과’로 집계하는 이름도 분리한다.

## 4. [높음] 분산 배정의 혼잡 모형이 시간·인원을 무시하고 후속 배정의 영향을 소급 반영하지 않음

- **위치:** `03_코드/cruise_route_optw.py:288`; `03_코드/run_B_model.py:57`, `:76`.
- **문제:** 같은 노드를 한 번 배정할 때마다 이후 그룹에 하루 내내 +8분을 더한다. 방문 시간이 겹치는지, 몇 명인지, 처리용량은 얼마인지 무관하다. 나중에 배정한 그룹이 먼저 도착해도 앞서 계산한 그룹의 대기는 고정된다. 모든 그룹 출발은 동일 시각인데 그림은 ‘하선 순서’라고 부른다.
- **구체적 결과:** 216.3→146.0분, 지각 4→0그룹은 이 순차 페널티의 시뮬레이션 결과다. 실제 혼잡 감소나 복귀 안전성의 검증값으로 쓰기 어렵다. 분산 쪽 지각 수는 재평가하지 않고 코드에 0으로 고정한다.
- **수정:** 그룹 규모·출발 시차·시간대별 노드 처리용량을 넣고, 전체 배정 완료 후 양쪽 경로를 같은 시간 기반 혼잡 평가기로 다시 평가한다. 당장은 ‘그룹당 +8분 가정 시 결과’로 표제에 명시하고 +8분 민감도를 제시한다.

- **문제:** A의 상륙가능시간은 체류−2.5시간이고 B는 추가 복귀버퍼 0.5시간을 차감한다. S1 예산은 8시간, S2는 3시간 45분으로 ‘7시간’과 다르다. 주력 체류 구간 상륙가능 중앙값도 8.47시간이다. 서사 루트 2·3의 깡깡이마을은 모델 노드 16개에 없고, 제시한 서사 순서에 대한 실행 가능성 검증도 없다.
- **구체적 결과:** 문학적 ‘7시간 동선’이 계산으로 검증된 산출물처럼 읽히지만, 현재 모델이 해당 경로를 만들거나 검사하지 않았다. 인문 해석과 산업수학 결과의 연결이 끊긴다.
- **수정:** 7시간을 특정 대상/서비스 예산 가정으로 정의하고 동일 예산 시나리오를 검증한다. 검증된 실제 경로에 서사 카드를 붙이거나 서사 루트를 별도 평가한다. 미포함 노드는 확장안으로 명시한다.

## 12. [중간] 음식별 설문 응답률을 넓은 카테고리에 전이하여 국적 선호를 왜곡

- **위치:** `03_코드/cruise_route_optw.py:42`, `:45`, `:133`; `02_정제데이터/국적선호_근거_1118_C.md`; `food_nodes_1118_B.csv` N12.
- **문제:** 장어구이 응답률을 ‘해산물’에 적용하므로 해산물로 분류된 동래파전에도 같은 가중치를 준다. 씨앗호떡→디저트 전이도 일반화다. 부산 방문 대만 관광객 설문이 크루즈 승객 효용을 직접 측정한 것은 아니며, `0.85 + 0.5 × 응답률/최대값` 변환은 팀의 임의 설계다.
- **구체적 결과:** 동래파전 효용이 장어 선호 때문에 약 0.995배가 되고, 국밥은 1.35배가 된다. S6의 차이를 검증된 대만 크루즈객 만족도 개선으로 해석하기 어렵다.
- **수정:** 응답 음식과 실제 제공 메뉴를 직접 매핑하고 미조사 음식은 기본값으로 둔다. 출처 모집단과 변환식을 명시하고, S6는 선호 가중 가정의 예시로 제시한다.

## 함께 확인한 사항 — 결함으로 단정하지 않은 부분

- **분기한정 상한:** 현재의 비음수 이동·대기·체류 입력에서는 최소 유입 이동시간을 뺀 `opt`와 최소 단계시간 기반 슬롯 수가 낙관적 상한을 구성한다. 복귀 비용 생략도 상한을 높이는 방향이다. 상한식 자체의 과소평가 버그는 발견하지 않았다. 다만 1번의 대기 선택 누락 때문에 일반 OPTW 정확해 주장은 여전히 성립하지 않는다.
- **복귀 검사:** DFS가 다음 상태로 갈 때 `end + T[n,depot] ≤ deadline`을 확인하므로 현재 상태의 `record`에 복귀 조건이 다시 없다는 이유만으로 버그라 할 수 없다.
- **Top-k:** `frozenset` 중복 제거는 ‘서로 다른 방문집합 K개’에 대한 설계다. 동일 장소의 다른 방문 순서까지 포함하는 일반적인 상위 K개 경로와는 다르므로 문서 정의를 맞추면 된다.
- **재현성:** 정제 CSV 17개를 UTF-8로 정상 파싱했고 원천 신고 CSV는 코드에 명시된 CP949로 읽혔다. 요청한 Python 코드의 외부 의존성은 허용 목록 안에 있다. 파일 실행 방식은 가능하지만 `__file__`을 쓰는 실행 스크립트는 Colab 셀에 그대로 붙이면 안 되며 업로드 후 파일 실행 안내가 필요하다. Linux의 `NanumGothic` 지정만으로 폰트 설치가 보장되지는 않는다.
- **심사 관점:** 우선순위는 산업수학의 정확성·비교 공정성(1~4), 사회과학의 모집단·분모 정합성(6~7), 지역 연계의 실제 배정·수요 타당성(5·10), 인문 서사와 산출물 연결(11)이다. 현 자료만으로 항목별 정밀 점수를 매기기보다 이 결함들을 먼저 고치는 편이 타당하다.
